Service Module Help Page

Warranties can be made from an equipment record.

  1. Find then view the required record.
  2. Click on the "Make Warranty" link.
  3. A new warranty form will be created with relevant fields filled with data from the equipment record.
  4. Click on Edit to fill in the other information.
  5. Save the record when finished. This will take you to the "View" screen.
  6. At the bottom of the form enter details of parts requested clicking on the Submit button to enter it into the list.
  7. Email the completed form to the appropriate persons by selecting their names from the list box e.g. product support managers. To send to multiple recipients hold down the "Ctrl" key on your keyboard while selecting each person. All selected name should be highlighted.
  8. Type a message to accompany the form in the text box.
  9. Click on the "Email It" button.
  10. If the send was OK a confirmation message should be displayed listing all the recipients the form was sent to.

PLEASE NOTE: Since TLD has so many different equipment there is a possibility of serial number duplication. To properly link a warranty to an equipment record you must create it using the "Make warranty" link from the equipment record. The "add" link on the warranty forms is for "oddball" warranties or for warranties not pertaining to any particular piece of equipment only. Another way would be to do a search in the warranties database for a serial number directly.

When a product support manager receives a warranty form:

  1. Search for the equipment record by doing a search on the serial number.
  2. This will list all warranties linked to chosen equipment record. Bring up the desired equipment record by clicking on the "Display" link.
  3. To automatically search for all warranties linked to this record click on the "Show warranties" link in the menu bar.
  4. This will take you to the warranties database and show a table of linked warranties found.
  5. Bring up the appropriate warranty by clicking on the "Display" link.
  6. Edit the warranty as appropriate.
  7. Save the warranty.
  8. Click on one of the "Accept","Reject" or "Conditional" links to mark the warranty.
  9. Please note that only persons with permissions greater than level 2 can mark warranties, i.e. product support managers or administrators.
  10. Only the original user who marks a warranty can change the status. To return a status back to "Pending" so that others can authorise it click on the "Click to reset status" link.
  11. Email the completed form to the appropriate persons by selecting their names from the list box e.g. service and parts. To send to multiple recipients hold down the "Ctrl" key on your keyboard while selecting each person. All selected name should be highlighted.
  12. Type a message to accompany the form in the text box.
  13. Click on the "Email It" button.
  14. If the send was OK a confirmation message should be displayed listing all the recipients the form was sent to.

PLEASE NOTE: It is not yet possible to directly enter spare parts orders into any of the order entry systems in use by each office. This feature will be added when the e-commerce site is setup.
